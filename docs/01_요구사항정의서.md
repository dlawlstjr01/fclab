## 1. 도메인과 선택 조건 충족 근거 (명세서 2.1)

**도메인: FC 온라인 선수 카드** — 넥슨 FC 온라인에 나오는 실존 축구 선수 카드.
사용자는 카드를 고르고, 그 선수의 실제 커리어와 FC 온라인 랭커 기록을 근거와 함께 묻고 · 소개받고 · 비교한다.

### 조건 1. 항목 메타데이터 — 약 100건 이상

| 항목 | 값 |
|---|---|
| 출처 | 넥슨 Open API — FC 온라인 메타데이터(`spid.json` 88,359장 · `seasonid.json` 153개 · `spposition.json`), 랭커 스탯 API |
| 미리 분석한 항목 | **432장** — 26 TOTS(현역 시즌 베스트) 161장 + ICON 145장 + ICON TM(ICON The Moment) 126장 |
| 그 밖의 카드 | 전체 **88,359장(선수 47,994명)** 모두 검색 · 선택 가능. 처음 열 때 같은 방법으로 분석해 저장 · 색인에 더한다 |
| 속성 | 이름, 시즌, 선수 이미지 · 시즌 아이콘, 같은 선수의 카드 수, 랭커 주 포지션, 랭커 경기당 평균(골 · 어시스트 · 슈팅 · 유효슈팅 · 패스 성공률 · 드리블 성공률 · 태클 · 블록), 위키백과 첫 문단 전문(국적 · 포지션 · 소속) |
| 랭커 스탯 보유 | 430장 (집계일 2026-10-20) — 랭커 스탯을 지원하지 않는 카드 4장은 일부 포지션만 |
| 만드는 법 | `python build_items.py` → `data/players.json` · `data/build_report.json` |

시즌을 고른 이유: 넥슨 Open API 테스트 키로는 전체 경기 목록(`/fconline/v1/match`)이 403 이라 '많이 쓰이는 카드'를 직접 셀 수 없었다.
그래서 위키백과 문서가 있을 가능성이 높은 시즌 — 지금 활약하는 선수(26 TOTS)와 은퇴한 레전드(ICON · ICON TM) — 을 미리 분석했다.
나머지 카드까지 미리 분석하지 않은 이유: 랭커 스탯이 카드 × 28포지션이라 88,359장이면 약 247만 쌍 조회가 필요하다. 시즌은 `settings.toml` 의 `items.seasons` 로 바꿀 수 있다.

### 조건 2. 외부 문서 출처와 이용 조건

| 출처 | 쓰는 곳 | 이용 조건 |
|---|---|---|
| 한국어 위키백과 API | 선수 자체 문서(항목마다 연결, 382/432장 — 동명이인 규칙으로 걸러 낸 후보 63건은 `data/build_report.json`), 질문마다 검색 · 선별해 모으는 클럽 · 대회 · 동료 문서 | CC BY-SA 4.0 — 제목 · 원문 링크 표시. User-Agent 연락처 · 호출 간격 준수 |
| 넥슨 Open API | 항목 메타데이터 · 이미지 | 넥슨 Open API 이용약관, "Data based on NEXON Open API" 표기, 키는 `.env` |
| 나무위키 | 🤖 AI로 찾기 중 수상 · 우승 · 기록 · '최고의 …' 같은 실제 세상 지식 조건의 선수 명단 근거 (문서 발췌) | CC BY-NC-SA 2.0 KR — 결과 화면에 문서 이름 · 링크 · 라이선스, 화면 하단에 출처. robots.txt 가 허용하는 문서 · 검색 화면만, 요청 사이 1.5초 |

### 조건 3. 근거 없이 답하면 틀리거나 위험해지는 질문

| # | 질문 | 근거 없이 답하면 |
|---|---|---|
| 1 | "26 TOTS 손흥민을 랭커들이 쓸 때 경기당 골은 몇 개야?" | 랭커 스탯은 매일 바뀌는 게임 데이터라 LLM 이 알 수 없다. 숫자를 지어낸다 |
| 2 | "하코보 라몬은 어느 클럽 유스 출신이야?" | 덜 알려진 26 TOTS 선수는 LLM 이 다른 선수와 섞어 그럴듯한 경력을 만든다 |
| 3 | "앨런 시어러의 프리미어리그 통산 득점과 득점왕 횟수는?" | 숫자 · 횟수가 조금씩 틀리기 쉽다. 근거 문서가 있어야 확인된다 |
| 4 | "두 선수 중 누가 국가대표 경기에 더 많이 나왔어?" | 두 사람의 기록을 모두 근거로 대야 하는 비교 질문 |

### 위험 도메인 여부

해당하지 않는다. 축구 선수 경력과 게임 기록이라 건강 · 금융처럼 판단이 위험하지 않다. 면책 안내는 두지 않는다(`data_prep/prompts.py` 의 `DISCLAIMER = None`).
게임 내 선수 구매를 권하는 문구는 쓰지 않고, 비교에서도 "누가 더 낫다"고 단정하지 않도록 프롬프트에 적었다.

| F2012 | UI | 진행 상태 및 안내 | 수집 · 색인 · 검색 · 답변 생성 단계를 진행 상태로 표시(근거 구성 진단 포함), 끝나면 수집된 문서 수. 키 누락 · 색인 없음 · 문서 없음 · 외부 API 실패 · 인용 없음 안내 | 필수 | `views/common.py` `boot()` · `run_with_status()` |
